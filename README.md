
MaterialTube — модифицированный YouTube-клиент на основе WizeStream, ориентированный на удобный просмотр видео и развитие современного интерфейса Android.

✨ Возможности

- 🌍 Подмена региона — настройка региона для получения контента.
- 🚫 Просмотр без рекламы — просмотр видео без встроенной рекламы платформы.
- 👤 Формы аватарок — изменение формы отображения аватаров.
- 🔌 Поддержка прокси — добавление и настройка собственных прокси.
- 📥 Импорт прокси — импорт конфигураций прокси.
- 🔤 Импорт шрифтов — добавление собственных шрифтов для персонализации приложения.
- ▶️ Shorts — поддержка коротких видео.
- 💻 Open Source — открытый исходный код для изучения и модификации.
